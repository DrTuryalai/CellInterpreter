# CellInterpreter: A Hybrid Natural Language Interface for Single-cell RNA-seq Analysis and Data-Driven Biological Interpretation
This repository contains the codes, processed scRNA-seq data, and results of the developed CellInterpreter platform. The platform is able to visually analyze and interpret scRNA-seq data of both human and animal. The platform can be used on any publicly available scRNA-seq data using both graphical user interface and natural language query assistant.

# Processed Dataset
The processed dataset folder contains the differential-expression data from an internal mouse food-allergy study. The data cover three tissues: heart, lung, and intestine, under two experimental conditions, BSA and OVA. They comprise cell-type-specific differential-expression results, with upregulated and downregulated genes represented separately. Each record includes gene identifiers and symbols, gene descriptions, average log2 fold changes, p-values, adjusted p-values, and the percentages of cells expressing each gene in the compared groups. Where available, Gene Ontology (GO) annotations and Kyoto Encyclopedia of Genes and Genomes (KEGG) pathway information are also included The dataset contains ranked differentially expressed genes, including the top 200 genes for the corresponding comparisons.
